Yolov8-Seg-HD 项目说明

这是 UnstoppableCurry/Yolov8-Seg-HD 的静态说明页。仓库是 Ultralytics YOLO 的训练向 fork，包版本字符串为 8.0.170（见 ultralytics/__init__.py）。

预定发布地址：https://unstoppablecurry.github.io/Yolov8-Seg-HD/

证据范围 仓库 README 很短，没有本项目的结果截图、日志或评测表。下列内容只复述 README 与可读源码。本页不提供准确率、速度、数据集规模、客户或产品输出。作者写在 README 里的目标（细粒度、边缘敏感、可在移动设备实时运行）视为意图陈述，本仓库没有可核对的运行证据。

作者在 README 中写了什么

  • 用途：训练细粒度、边缘敏感、高清的端到端分割检测算法，并希望能在移动设备上实时运行。
  • API：声称与当时 Ultralytics 用法对齐；不支持上游此后新增的一些能力（README 举例：可视化、旋转）。作者将其视为与 2023 年左右 的 Ultralytics 一致。
  • 取向：相对官方「更简单的 API」，作者称这个 fork 对开发者改结构更友好，对一般调用者不那么友好。
  • 数据：训练/验证目录下同时放 images、labels（.txt）和 label（.png）；README 要求 PNG 与 TXT 对应，并称 TXT 轮廓对应二值图上的白色区域。

源码里能核对的「HD」差异

与同仓库里未改动的 Proto 副本（ultralytics/nn/modules/block_1.py）以及官方常见实现相比，当前被导入的 ultralytics/nn/modules/block.py 把掩码原型上采样从 1 次 ×2 改成 3 次 ×2。YOLOv8-seg 的原型输入来自 P3（步幅 8），三次上采样后空间尺寸约为输入图的 1:1。这是本页能从源码直接读出的高分辨率分割改动。

配套默认项：ultralytics/cfg/default.yaml 中 mask_ratio: 1（上游常见默认多为 4）；根目录 yolov8-seg.yaml 的 Segment 参数为 [nc, 4, 32]（掩码系数通道 4、原型通道 32），与包内 ultralytics/cfg/models/v8/yolov8-seg.yaml 的 [nc, 32, 256] 不同。详见 源码改动。

本仓库没有项目专用结果图。若你在其他页面看到 Ultralytics 风格配图，一律按上游样例理解。

本页不覆盖的内容

  • 没有公布可复现的公开数据集；coco128-seg-seal.yaml 与 train.py 指向本机 Windows 路径，数据不在本仓库。
  • 根目录有 yolov8n.pt，文件名是检测权重，本页不把它当作分割训练成果。
  • 许可证头为 AGPL-3.0；仓库根目录没有单独的 LICENSE 文件。
